# Web UI scope

The local web interface is a configuration and diagnostics surface, not a controller.

Initial pages should cover:
- device status
- Wi-Fi setup
- indoor/outdoor BLE selection
- target temperature
- aggressiveness
- electricity area and location
- Ohmonwifiplus setup/status
- optional MQTT setup
- learning diagnostics/reset

The UI must continue to work on a local LAN without Home Assistant.
