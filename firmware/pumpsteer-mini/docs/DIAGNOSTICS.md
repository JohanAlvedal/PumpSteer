# Diagnostics scope

Diagnostics should make every control decision explainable.

Planned fields include:
- operating mode
- indoor/outdoor/fake temperature
- target temperature
- PI error/P/I terms
- price class and relevant thresholds
- brake/preheat/precool factors
- sensor freshness and RSSI
- internet/price/forecast freshness
- Ohmonwifiplus health
- learning sample count/confidence/model values
- last safe-mode reason

Diagnostics must not expose credentials.
